# uChurch v17.11.78

## Русский

Выполнено выравнивание активной версии и рабочих инструкций для закрытого
пилота. Проверка теперь сопоставляет маркеры версии клиента, сервера,
конфигурационных примеров и package metadata.

Документация точнее разделяет две среды: `staging.uchurch.ru` остаётся
постоянной синтетической Demo, а отдельный pilot-контур может рассматриваться
только после проверяемой синтетической репетиции и явного решения владельца.

Реальные базы церквей, пароли и recovery-файлы не использовались и не
публиковались.

## English

Active version markers and operating instructions were aligned for the closed
pilot. The consistency check now compares client, server, environment-example,
and package metadata markers.

Documentation now separates the permanent synthetic Demo staging environment
from a future owner-approved pilot environment. No church databases, passwords,
or recovery files were used or published.

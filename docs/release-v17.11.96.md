# uChurch v17.11.96

The small game on the uChurch waiting page now remembers each solved picture.
Up to three photographs appear in a restrained gallery and can be opened in a
larger zoomable view.

The progress is local to the visitor's browser and contains only photo numbers.
It does not contain church records, accounts or tracking identifiers. The three
approved site photographs are now optimized public assets, so the page can be
restored completely from the public repository.

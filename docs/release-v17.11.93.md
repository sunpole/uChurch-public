# uChurch v17.11.93

## Русский

Единый зашифрованный `.uchurchdb` закреплён как рабочий формат базы владельца.
На полностью синтетических данных проверен полный цикл: перенос копии старого
формата, изменение и добавление записи, скачивание, завершение сессии и
повторное открытие без потери остальных данных. Реальная церковная база в
проверке не использовалась.

## English

The encrypted `.uchurchdb` package is now the documented owner-held working
database format. A fully synthetic cycle verifies migration from an older
copy, edit and add operations, download, session end, and exact reopening.
No real church database was used.

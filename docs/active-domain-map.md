# Действующие адреса uChurch

Актуализировано: 2026-10-07.

| Адрес | Назначение |
| --- | --- |
| https://uchurch.pro/ | Авторская главная страница и вход в проект |
| https://staging.uchurch.pro/ | Синтетическая Demo с временными изменениями |
| https://pilot.uchurch.pro/ | Открытый MVP: новая база или зашифрованная копия пользователя |
| https://sunpole.github.io/uChurch-public/ | Публичная витрина, каталог патчей и очередь развития |

Технические контуры возвращают `noindex`. Это правило индексации, а не
контроль доступа. Старые адреса `.ru` больше не используются для навигации
и восстановления. Их упоминания в датированных заметках относятся к истории.

Витрина не хранит базы, журналы CRM, пароли, recovery-файлы или конфигурацию
сервера. Исходники главной страницы полностью находятся в
`landing/uchurch.pro/`. Рабочее ядро восстанавливается из точного тега
отдельного приватного репозитория; данные и секреты владелец хранит отдельно.

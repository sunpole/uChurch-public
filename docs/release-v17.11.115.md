# v17.11.115 — DIRECTORY-UX

Рабочий MVP публичного справочника получил объединённый дизайн 2+3:
широкий список, тёмная нейтральная палитра, зелёные акценты и цветные теги.
Это не изменение CRM или пользовательской базы.

- Два типа, постоянные номера, источники и подтверждённые даты сохранены.
- Все/Долги/Патчи переключаются сразу, поиск доступен над списком.
- Номер, несколько частей и даты находятся в раскрывающихся фильтрах.
  Активные условия видны отдельно и снимаются по одному.
- Запись открывается целиком в панели; на телефоне она занимает экран.
  Escape/закрытие возвращают фокус и сохраняют выбранные фильтры.
- Исправлен поиск по #номеру. Сортировка, страницы, RU/EN и URL сохраняются.
- Для 640x480/800x600 есть компактная шапка без уменьшения основного текста.
  Иконки Lucide хранятся локально; тяжёлых эффектов, шрифтов/CDN и CRM-данных нет.

Неизвестные даты остаются прочерками. Старые патчи пока находятся в прежней
истории, их перенос — отдельный долг. Цвет тега дополняет текст, не заменяет его.
Это адаптация к размерам экрана, не обещание поддержки IE6 или Windows XP.

# v17.11.110: TABLE-COLUMNS

Status: installed and live-verified on Demo/Pilot, 2026-10-09.

## Что изменилось

- Выбранные столбцы появляются на настроенном месте, а не в конце таблицы.
- Изменения из Админки и панели проекта применяются, даже когда открыт другой
  раздел; возврат в Таблицу не требует перезагрузки.
- Настроенный в Админке порядок больше не заменяется старым состоянием.
  Сортировка, поиск и ширина проверяются регрессией.
- Help на русском и английском объясняет: Админка разрешает поля и порядок
  для базы, панель выбирает разрешённые поля для текущего браузера.
  Скрытие не удаляет данные; личный выбор не переносится на другой ПК.

## Проверки и границы

Отдельный синтетический сценарий проверяет четыре размера экрана, переходы,
скрытие/возврат/перестановку, отказ сохранения и повтор, перезагрузку,
проверенный экспорт и открытие скачанного пакета, неизменность пяти частей
и метаданных. Результат выпуска: [квитанция](release-v17.11.110-receipt.md).

Формат `.uchurchdb` v1, шифрование, API и временная модель сессии не меняются.
Реальные базы не используются в проверках и не публикуются. Проверки не
являются серверным стресс-тестом, полным DR1 или гарантией отсутствия ошибок.
Живой smoke прошёл New/Open, настройки столбцов, правку Карточки, скачивание
базы/recovery и повторное открытие; все пять частей и метаданные сверены.
Работающий сервер остаётся v17.11.110; пользовательская приёмка открыта.
Сообщение об отказе сохранения Админки пока находится в панели проекта;
его перенос к кнопке и обязательный GitHub CI остаются отдельными задачами.

## Восстановление

Исходники восстанавливаются из неизменяемого private tag; публичный репозиторий
содержит только документацию и безопасную историю. Предыдущий v17.11.109
сохраняется, теги не передвигаются. До установки сохраняются исходники,
конфигурация и образы; после неё создаётся отдельная SHA256-проверенная копия.
Откат затрагивает только приложение. Перезапуск удаляет временные сессии и
аварийные снимки: сначала скачать работу и завершить сеанс. Пользовательские
файлы базы и соответствующие recovery хранятся владельцем отдельно от Git.

# uChurch v17.11.47

## Русский

DEP0 подготовил техническую основу для отдельного тестового окружения uChurch.
Будущий серверный запуск использует только синтетическую Demo-базу, изолированный
контейнер и проверку готовности без сведений о людях или данных церкви.

Тестовый адрес и HTTPS ещё не опубликованы: для этого отдельно требуются DNS,
серверная проверка Docker и измерение ресурсов. Базы церквей, резервные копии,
ключи восстановления и исходный код CRM не входят в эту публичную заметку.

## English

DEP0 prepares the technical foundation for a separate uChurch staging
environment. The future server run uses only a synthetic Demo database, an
isolated container, and a readiness check with no people or church-data
details.

The staging address and HTTPS are not published yet: DNS, a server-side Docker
check, and resource measurements remain separate acceptance work. Church
databases, backups, recovery keys, and CRM source code are not part of this
public note.

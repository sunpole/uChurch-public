# uChurch v17.11.87

## Русский

Публичная кнопка Demo теперь открывает отдельную синтетическую сессию сразу.
Повторные быстрые нажатия не создают несколько параллельных Demo-сессий. Demo
остаётся учебной средой: изменения не становятся серверной базой и исчезают
после обновления страницы.

## English

The public Demo action now opens one dedicated synthetic session directly.
Repeated rapid clicks cannot create parallel Demo sessions. Demo remains a
learning environment: changes never become a server database and disappear
after a page refresh.

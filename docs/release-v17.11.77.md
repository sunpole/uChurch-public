# uChurch v17.11.77

## Русский

Усилена проверка развёртывания синтетической среды. Перед обновлением система
теперь заранее проверяет обязательные условия запуска и ждёт подтверждения
работоспособности.

Это техническое исправление не меняет CRM, правила работы с базами или границу
между тестовыми и церковными данными.

## English

Synthetic-environment deployment verification was strengthened. Before an
update, the system now checks required startup conditions and waits for a
health confirmation.

This technical correction does not change the CRM, database rules, or the
boundary between test and church data.

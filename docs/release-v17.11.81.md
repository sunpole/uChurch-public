# uChurch v17.11.81

## Русский

В синтетической Demo появился понятный первый шаг. Кнопка запускает отдельную
временную сессию с оператором «Демо», чтобы интерфейс можно было изучать без
изменения исходного Demo шаблона.

`staging.uchurch.ru` остаётся только синтетической средой. Базы церквей,
пароли, recovery файлы и приглашения не включались.

## English

The synthetic Demo now has a clear first step. It starts an isolated temporary
session with the Demo operator without changing the source fixture.

Staging remains synthetic only. Church databases, passwords, recovery files,
and invitations were not enabled.

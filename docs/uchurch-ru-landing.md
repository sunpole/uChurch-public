# Страница uchurch.ru

Публичная входная страница хранится в
`landing/uchurch.ru/index.html`. Это статический HTML без CRM кода, форм
данных, аналитики и секретов.

Три разрешённые владельцем фотографии пятнашек находятся в
`landing/uchurch.ru/assets/` как оптимизированные WebP. Исходные PNG хранятся
во внешней резервной копии владельца. После решения пятнашки браузер сохраняет
только номер открытой фотографии в versioned `localStorage`; данных CRM или
идентификаторов посетителя там нет.

На широком экране открытые фотографии образуют спокойный ряд рядом с игрой,
на телефоне горизонтальную ленту под ней. Фотография открывается в отдельном
окне со стандартным pinch zoom, кнопками масштаба, закрытием по фону и
клавишей `Escape`.

После открытия первой фотографии появляется одна кнопка «Скрыть фото». Она
плавно растворяет ряд, но остаётся доступной как «Показать фото». Выбор
сохраняется локально в браузере и не содержит пользовательских данных.

## Маршруты

- «Попробовать демо» открывает `https://staging.uchurch.ru`, где доступны
  только синтетические данные.
- «Начать работу» открывает `https://pilot.uchurch.ru`. Там владелец может
  создать новую временную базу или открыть свой последний зашифрованный пакет.
  Сервер не хранит рабочую базу после завершения сессии.

## Обновление VPS

Перед заменой статической страницы администратор создаёт резервную копию всего
каталога `/var/www/uchurch.ru`, фиксирует SHA256 нового `index.html` и проверяет
новую страницу на desktop и телефоне. На VPS переносится всё содержимое
`landing/uchurch.ru/`: HTML, `robots.txt`, `sitemap.xml` и каталог `assets`.
Копирование только `index.html` оставит SEO-файлы и изображения за пределами
восстанавливаемого релиза.

Новый каталог сначала загружается в owner-controlled staging directory в
`/home/anton`, затем администратор с `sudo` создаёт backup текущего web root и
устанавливает проверенные файлы. Конфигурация PRE.BY и контуры staging/pilot не
изменяются. Старые корневые `photo1.png`, `photo2.png`, `photo3.png` после
backup не используются: релиз ссылается только на `assets/photo*.webp`.

Проверка после размещения: `https://uchurch.ru` отвечает по HTTPS, обе ссылки
ведут на нужные hostname, а страница не содержит данных, паролей, приглашений
или recovery материала.

## Индексация

`uchurch.ru` является единственным публичным индексируемым адресом. Его
canonical URL, описание, Open Graph metadata, `robots.txt` и `sitemap.xml`
хранятся рядом с HTML. Sitemap содержит только главную страницу.

`staging.uchurch.ru` и `pilot.uchurch.ru` не входят в sitemap и возвращают
`X-Robots-Tag: noindex, nofollow` из Nginx. Это указание поисковику, а не
средство защиты или способ скрыть публично доступный адрес.

После размещения владелец добавляет доменное свойство `uchurch.ru` в Google
Search Console, отправляет `https://uchurch.ru/sitemap.xml` и запрашивает
индексацию только главной страницы.

## Визуальная проверка

Мини игра сохраняет отдельные области для доски и строки подсказки со счётчиком.
Проверяются 1024x680, 1280x720, 1366x768, 1920x1080, 2560x1440,
3840x2160, 412x914 и 321x914. На странице разрешено стандартное
масштабирование браузера и поддерживается системная настройка reduced motion.

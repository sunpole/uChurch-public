# Страница uchurch.ru

Публичная входная страница хранится в
`landing/uchurch.ru/index.html`. Это статический HTML без CRM кода, форм
данных, аналитики и секретов.

## Маршруты

- «Попробовать демо» открывает `https://staging.uchurch.ru`, где доступны
  только синтетические данные.
- «Начать работу» открывает `https://pilot.uchurch.ru`. Там владелец может
  создать новую временную базу или открыть свой последний зашифрованный пакет.
  Сервер не хранит рабочую базу после завершения сессии.

## Обновление VPS

Перед заменой статического файла администратор создаёт локальную резервную
копию текущего `/var/www/uchurch.ru/index.html`, фиксирует SHA256 и проверяет
новую страницу на desktop и телефоне. Меняется только этот HTML файл в
существующем vhost `uchurch.ru`; конфигурация PRE.BY и контуры staging/pilot не
изменяются.

Проверка после размещения: `https://uchurch.ru` отвечает по HTTPS, обе ссылки
ведут на нужные hostname, а страница не содержит данных, паролей, приглашений
или recovery материала.

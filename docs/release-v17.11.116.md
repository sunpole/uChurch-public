# uChurch v17.11.116 — обновление зависимостей

Обновлены две зависимости сервера и сборки интерфейса. На обоих стендах проверены открытие временной Demo-сессии и чтение её синтетических данных. Остальные обновления зависимостей остаются в очереди.

На Staging и Pilot проверены версия, готовность сервиса и завершение тестовой сессии. Для этого обновления пользователям не требуется переносить базу.

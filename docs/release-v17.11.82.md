# uChurch v17.11.82

## Русский

Публичная страница `uchurch.ru` стала управляемой частью витрины проекта.
Она сохранила спокойный авторский экран и получила два ясных входа:
синтетическая Demo и отдельный пре альфа контур.

Страница не обрабатывает CRM данные и не является хранилищем базы. Demo ведёт
только в synthetic staging, а защищённый контур по прежнему требует отдельного
допуска.

## English

The public `uchurch.ru` page is now maintained from the project storefront. It
keeps its original calm visual language and provides separate Demo and
pre-alpha entry routes.

The page does not process or store CRM data. Demo points only to synthetic
staging, while the protected route remains separately gated.

# uChurch v17.11.48

## Русский

WEB1 проверяет фундамент переносимого зашифрованного пакета базы только на
синтетической Demo-базе. Проверены защита парольной фразой, отдельный файл
восстановления и контроль целостности пакета. Эта версия не открывает
веб-загрузку, не подключает Google Drive и не принимает реальные базы церквей.

Следующий отдельный этап создаст временную изолированную веб-сессию также
исключительно для синтетических данных.

## English

WEB1 validates the foundation of a portable encrypted database package only on
the synthetic Demo database. Password protection, a separate recovery file,
and package integrity checks were verified. This release does not open web
upload, connect Google Drive, or accept real church databases.

The next separate stage will create a temporary isolated web session, also for
synthetic data only.

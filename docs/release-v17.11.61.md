# uChurch v17.11.61

## Русский

В `v17.11.57-v17.11.61` на синтетическом staging появился честный старт
временной веб-сессии. Можно открыть изолированную Тестовую базу с 50
вымышленными людьми либо создать пустую временную базу и указать её
операторов. Пустая сессия не подключает папки, не принимает файлы и удаляет
данные по завершении сессии.

Реальные церковные базы по-прежнему не принимаются сервером. Скачивание
зашифрованной копии и явное завершение сессии будут добавлены отдельным
следующим этапом.

## English

`v17.11.57-v17.11.61` adds an explicit start for synthetic staging sessions.
Visitors can open an isolated Test database with 50 fictional people or create
a blank temporary database and specify its operators. A blank session attaches
no folder, accepts no files, and deletes its data when the session ends.

The server still does not accept real church databases. Encrypted download and
an explicit session exit remain a separate next step.

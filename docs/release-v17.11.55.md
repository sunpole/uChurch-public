# uChurch v17.11.55

## Русский

В `v17.11.52-v17.11.55` обновлена компактная работа с интерфейсом: название
проекта остаётся обычным текстом, команды базы собраны в одно меню, а Таблица
получила отдельную панель управления отображением. На малых экранах список
разделов заменяется ясным селектором, чтобы навигация не обрезалась.

Проверка выполнена на `staging.uchurch.ru` с синтетической Demo-базой. В
публичный staging не загружались реальные базы церквей, пользовательские файлы,
ключи или recovery-материалы.

## English

`v17.11.52-v17.11.55` improves compact workspace controls: the project name
remains plain text, database actions live in one menu, and Table display
controls have their own compact panel. On small screens, a clear view selector
replaces clipped navigation.

The change was checked on `staging.uchurch.ru` using a synthetic Demo database
only. No real church database, user file, key, or recovery material was
uploaded to public staging.

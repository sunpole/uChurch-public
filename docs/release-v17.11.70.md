# uChurch v17.11.70

## Русский

Усилены технические границы временной веб сессии и проверки перед будущим
закрытым пилотом. Staging остаётся только синтетической Demo средой: реальные
базы церквей, ключи восстановления и персональные данные туда не принимаются.

Это не открытие пилота. Перед следующим этапом остаются независимая проверка
безопасности, отдельный закрытый адрес и синтетическая репетиция полного цикла.

## English

Technical boundaries for temporary web sessions and checks for the future
closed pilot have been strengthened. Staging remains a synthetic Demo-only
environment: it does not accept church databases, recovery material, or
personal data.

This does not open the pilot. An independent security review, a separate
private endpoint, and a synthetic full-cycle rehearsal remain before it.

# uChurch v17.11.43

Добавлена одна постоянная синтетическая Тестовая база для внутренней
инженерной проверки. Она создаётся из неизменяемого Demo-шаблона, не содержит
данных церкви и остаётся вне публичных материалов.

Сброс Тестовой базы требует явного подтверждения и сначала создаёт отдельную
резервную копию. Пользовательские базы, экспорт, журналы и исходный код CRM в
публичную витрину не добавляются.

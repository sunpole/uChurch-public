# uChurch v17.11.75

## Русский

Улучшена защита HTTPS для отдельной синтетической среды проверки. Адрес
использует более строгую политику защищённого соединения, а конфигурация
проверяется автоматически перед развёртыванием.

Работа по-прежнему ведётся только на вымышленных Test данных. Базы церквей,
файлы восстановления и персональная информация не используются.

## English

HTTPS transport protection was improved for the separate synthetic verification
environment. The address uses a stricter secure-connection policy, and the
configuration is checked automatically before deployment.

Work still uses fictional Test data only. Church databases, recovery files,
and personal information are not used.

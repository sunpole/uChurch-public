# uChurch v17.11.69

## Русский

В web Demo восстановлена удобная навигация для телефона. Основные рабочие
разделы доступны в постоянной нижней панели, а действия с проектом собраны в
выдвижной панели справа: оператор, сохранение, скачивание, настройки Таблицы,
язык, Help и Админка.

Название uChurch открывает экран начала работы, не завершая активную временную
сессию. Staging по-прежнему использует только синтетическую Demo-базу и не
принимает реальные базы церквей.

## English

The web Demo now has a usable phone navigation. Primary work areas are in a
persistent bottom bar, while project actions are collected in a right-side
panel: operator, saving, download, Table settings, language, Help, and Admin.

The uChurch name opens Start Center without ending an active temporary session.
Staging still uses only the synthetic Demo database and does not accept real
church databases.

# uChurch v17.11.94

## Русский

Главная страница `uchurch.ru` получила единый canonical URL, поисковое описание,
Open Graph metadata, `robots.txt` и sitemap только с публичным адресом. Pilot и
staging исключены из поиска отдельным серверным `noindex`; их прямые адреса
остаются технически доступными.

## English

The `uchurch.ru` landing now has one canonical URL, search description, Open
Graph metadata, robots rules, and a sitemap containing only the public entry.
Pilot and staging are excluded from search through a server-side `noindex`
header while remaining directly reachable technical hosts.

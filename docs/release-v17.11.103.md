# uChurch v17.11.103

## RU

Небольшое исправление рабочего входа Pilot.

- При нескольких быстрых попытках открыть зашифрованную копию временное
  ограничение теперь показывается честно и нейтрально. Оно не выглядит как
  повреждение базы или ошибка пароль-фразы.
- В создании новой базы кнопка «Назад» возвращает к названию церкви и не
  стирает уже введённый текст.

Проверки и выпуск использовали только synthetic данные. Базы церквей, пароли,
recovery-файлы, журналы и выгрузки не входят в этот публичный релиз.

## EN

A small Pilot working-entry correction.

- Repeated rapid attempts to open an encrypted copy now receive a clear,
  neutral temporary limit response instead of appearing to be a damaged file
  or an incorrect password phrase.
- In new database setup, Back returns to the church-name step without clearing
  the entered text.

Verification and release used synthetic data only. Church databases, passwords,
recovery files, logs and exports are not part of this public release.

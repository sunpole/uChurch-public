# Публичный план uChurch

## Сейчас

1. Приватное ядро разработчиков и публичная витрина разделяются.
2. Synthetic staging поддерживает явный старт Тестовой или пустой временной
   сессии; реальные базы церквей сервер не принимает.
3. Публичная витрина публикует русские новости разработки через uNews.
4. `uchurch.ru` служит публичным входом: Demo ведёт только на synthetic staging,
   а пре альфа вход ведёт в отдельный закрытый контур.

## До закрытой web beta

1. Пройти независимую security-проверку и репетицию закрытого пилота только на
   синтетических данных.
2. Настроить отдельный private pilot host, не заменяя synthetic staging.
3. Только после принятых проверок провести контролируемую совместимость на
   копии существующей базы церкви. Оригинал остаётся нетронутым.
4. До завершения этих шагов реальная база церкви через интернет не открывается.

Постоянное облачное хранение, аккаунты, совместная работа и платежи не входят
в первый этап web beta.

Ближайший этап: проверяемые ворота пре альфа, затем независимая
security-проверка и синтетическая репетиция закрытого пилота. Реальные базы до
отдельного security gate запрещены.

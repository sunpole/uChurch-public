# Публичный план uChurch

## Сейчас

1. Приватное ядро разработчиков и публичная витрина разделяются.
2. Synthetic staging поддерживает явный старт Тестовой или пустой временной
   сессии; реальные базы церквей сервер не принимает.
3. Публичная витрина публикует русские новости разработки через uNews.

## До web Demo

1. Утвердить модель конфиденциальности и угроз.
2. Подготовить web-экран приветствия и каталога возможностей.
3. Проверить расчёты и ключевые пользовательские сценарии на синтетических
   данных.
4. Открыть web Demo без возможности загрузить базу церкви.

## До закрытой web beta

1. Создать зашифрованный переносимый пакет базы с проверкой целостности.
2. Проверено на синтетической Demo: временная изолированная сессия без постоянного хранения на сервере.
3. Добавить явные действия сохранения, скачивания и завершения сессии.
4. Добавить доступ по приглашению, HTTPS, ограничения запросов, мониторинг
   удаления сессий, нагрузочную и независимую security-проверку.

Постоянное облачное хранение, аккаунты, совместная работа и платежи не входят
в первый этап web beta.

Ближайший этап: явные действия сохранения, скачивания и завершения
синтетической временной сессии. Реальные базы до отдельного security gate
запрещены.

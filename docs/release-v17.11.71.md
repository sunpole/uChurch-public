# uChurch v17.11.71

## Русский

Подготовлен отдельный закрытый контур будущего pilot режима. Он изолирован от
Demo окружения, по умолчанию выключен и не принимает базы церквей, ключи
восстановления или персональные данные.

`staging.uchurch.ru` продолжает работать только с синтетической Test базой.
До закрытого pilot режима остаются независимая проверка безопасности, отдельный
адрес и синтетическая репетиция полного цикла.

## English

An isolated deployment contract for a future closed pilot has been prepared.
It is disabled by default and does not accept church databases, recovery
material, or personal data.

`staging.uchurch.ru` remains a synthetic Test-only environment. An independent
security review, a separate endpoint, and a full synthetic rehearsal are still
required before a closed pilot.

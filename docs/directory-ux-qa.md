# DIRECTORY-UX v17.11.115 — проверки

Автоматический сценарий: scripts/check-work-directory-browser.mjs.
Модель: scripts/check-work-directory.mjs. Проверки выполняются на публичных
инженерных записях и дополнительных вымышленных строках, не на CRM-данных.

- Совместные фильтры, точный номер, #поиск, два диапазона дат и их ошибка,
  снятие одного условия, сброс, сортировки, URL/reload и RU/EN: PASS.
- Полный текст/даты/источник, Escape, возврат и удержание фокуса, Enter/Tab,
  touch и неизменные фильтры после закрытия подробностей: PASS.
- 320x568, 360x640, 412x915, 640x480, 800x600, 1024x680, 1024x768,
  1280x720, 1366x768, 1440x1024, 1920x1080, 2560x1440, 3840x2160: PASS.
  Нет горизонтального overflow; первая запись/заголовок доступны на первом
  экране. Подробности и панель фильтров не выходят за доступную ширину.
- Эквивалент 200%:720 CSS px при2x device scale для1440 device px, без
  overflow. Это эмуляция reflow, не проверка физического устройства или
  успешного Ctrl-plus в интерфейсе встроенного браузера.
- Контраст текста цветных тегов >=4.5:1; reduced motion отключает переходы.
  Полная сертификация WCAG и работа всех screen reader не заявляются.
- Пагинация25/100, 100 добавленных тестовых строк, 30 быстрых смен поиска,
  безопасный вывод HTML-подобного текста, blocked storage и fallback при
  некорректном ответе данных: PASS. Это не стресс-тест VPS.
- Все28 старых записей сравнены с внешним before snapshot и неизменны;
  добавлена только правдивая запись нового UI-патча29. Старые патчи не импортированы.

В ходе QA исправлены невысокий640x480 экран, удержание фокуса, небольшая
типографика, нестабильное положение фильтров и доступность закрытия при
прокрутке. Первые неудачные прогоны не считаются успешными.

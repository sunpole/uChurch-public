# v17.11.108 — SESSION-SAVE

Дата: 7 октября 2026. Формат `.uchurchdb` v1 сохранён.

Активная работа больше не обрывается стандартным абсолютным пределом 30 минут.
Без действий внутри CRM предупреждение появляется на 25-й минуте, очистка
временной серверной базы происходит на 30-й. Предупреждение не блокирует
редактор и экспорт. Выход сначала предлагает проверенную зашифрованную копию.

Есть почасовое напоминание и необязательные локальные автокопии: пользователь
выбирает папку, готовит первый пакет и разрешает держать пароль в памяти
вкладки. Новые зашифрованные копии записываются с проверкой прочтения, прежние
не удаляются. Без поддержки браузера или разрешения остаётся ручное скачивание.
При истечении серверной сессии живой вкладке доступен последний подготовленный
пакет, а не гарантированно все последующие правки.

Проверено только на синтетических данных: ускоренные таймеры, два часа активной
сессии, цикл изменения/экспорта/открытия всех частей, отказ неверного CSRF,
коллизии и ошибки записи, почасовое напоминание, неблокирующий отсчёт,
браузерные файловые API и четыре размера экрана. Ограниченный локальный тест
100 запросов не является измерением ёмкости сервера или доказательством защиты
от DDoS. Нативное окно выбора папки и длительная работа Ольги требуют её проверки.

Публичный каталог дополнен всеми сохранившимися документированными записями;
номера без доказательств не придуманы. Долги SR1, DR1, UX3/UX2 и COLLAB1 открыты.
Email, Telegram и временная ссылка для восстановления — отдельный будущий проект.

Реальные церковные данные, базы, ключи и recovery не публиковались. Обращение
Ольги остаётся открытым до её личного подтверждения результата.

# uChurch v17.11.83

## Русский

В отдельном пре альфа контуре появился нейтральный вход по приглашению.
Интерфейс не показывает и не сохраняет код. После успешной проверки доступны
только безопасные дальнейшие действия, а открытие зашифрованной пользовательской
базы остаётся выключенным до следующих принятых проверок.

## English

The separate pre-alpha environment now has a neutral invitation entry. The
interface never displays or stores a code. After a successful check, only safe
next actions are available; encrypted user-package opening remains disabled
until later accepted checks.

# Открытые задачи uChurch

Сверка: 13 октября 2026. Реализованное, проверенное и принятое пользователем
отмечается отдельно. Список не означает завершение всех проверок безопасности.

Первичный [справочник с фильтрами](../catalog.html) заполнен прежде всего долгами.
Постоянные номера, два типа и правила дат описаны в [правилах](work-directory.md).
Исторические патчи пока остаются в истории версий. №7 относится к справочнику,
остальные номера назначены при его создании и не повторяют номера жалоб.
Первичный список не доказывает завершение сверки всех архивов и прежних чатов.

Уточнение текущего статуса: этапы духовного роста и их порядок приняты владельцем
после v17.11.112; атомарность связанных сохранений остаётся отдельным долгом.
Таблица ниже отражает уточнённый статус, прежние release notes не переписаны.

Дополнительно в справочник включены: повторная проверка первого кадра Demo,
решение о переносе истории Корзины/Журнала в пакет, DA2-C синтетические сценарии,
сверка устаревших активных инструкций, проект read-only консультации и оценка
upstream-защиты от DDoS. Это отдельные незавершённые работы, не обещания функций.

BACKUP1 v17.11.100 и CORE-QA v17.11.101 имеют синтетические доказательства.
Открытие перенесённого файла оператором подтверждено владельцем; содержимое
реальных баз не используется для публичной QA и не публикуется.

Каждый следующий патч должен фиксировать точный тег, проверенные результаты,
остаток долга и статус установки. Рабочая копия пользователя не является
частью публичного репозитория.

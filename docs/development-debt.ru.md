# Открытые задачи uChurch

Сверка: 7 октября 2026. Реализованное, проверенное и принятое пользователем
отмечается отдельно. Список не означает завершение всех проверок безопасности.

| Приоритет | Этап | Состояние и критерий завершения |
| --- | --- | --- |
| Высокий | SEC1 | Проверка и обновление зависимостей с новыми advisory. Октябрьская сборка сообщает critical в server dependency и high в клиентской цепочке сборки. SESSION-SAVE не закрывает этот долг. |
| Высокий | SESSION-SAVE | Исправление жалобы на 30-минутное завершение: активность, 30 минут простоя, неблокирующее предупреждение, экспорт перед выходом и добровольные автокопии. Требуется проверка оператором после установки. |
| Регулярно | SHOWCASE | Каталог дополнен документированной историей, актуальными адресами, релизами и статусами долгов. После каждого принятого патча повторять сверку опубликованной витрины. |
| Высокий | SR1 | Измерение серверной нагрузки, обоснованные пределы, monitoring, алерты и проверка restart. Локальный ограниченный нагрузочный тест не закрывает SR1. |
| Высокий | DR1 | Повторяемое восстановление из точного исходного тега, защищённой конфигурации и независимых копий; полная репетиция на чистом окружении ещё нужна. |
| Средний | UX3 | Единое безопасное Назад/Главная/Завершить на всех уровнях; поведение при нескачанной работе и обрывах. Закрывается сценариями и пользовательской приёмкой. |
| Средний | UX2 | Единый стиль и исправление вёрстки CRM: старые ноутбуки, 1024x680, 1280x720, 1366x768, 1080p, 1440p, 4K и телефоны. |
| Средний | PORT1 | Переезд на `.pro` выполнен; подготовка к следующей смене домена и независимая репетиция восстановления ещё не завершены. |
| После стабильного одиночного цикла | COLLAB1 | Проект общей базы, прав, конфликтов и единой версии данных. Общий код или ссылка сами по себе не синхронизируют файлы. |
| Отдельное решение | BACKUP-DELIVERY | Передача зашифрованной копии в почту/Telegram или временная ссылка: подтверждение получателя, срок, отзыв, проверка доступа и пределы хранения. Пока только предложение. |
| Отложено | OFFLINE / CLOUD | Офлайн CRM, Drive API, синхронизация и внешнее ежемесячное копирование исходников. Срок не назначен. |

BACKUP1 v17.11.100 и CORE-QA v17.11.101 имеют синтетические доказательства.
Открытие перенесённого файла оператором подтверждено владельцем; содержимое
реальных баз не используется для публичной QA и не публикуется.

Каждый следующий патч должен фиксировать точный тег, проверенные результаты,
остаток долга и статус установки. Рабочая копия пользователя не является
частью публичного репозитория.

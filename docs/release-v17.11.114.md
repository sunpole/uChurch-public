# v17.11.114 — DIRECTORY

На публичной витрине появился [справочник долгов и патчей](../catalog.html).
По решению владельца первично заполнены долги, а не архив всех старых патчей.
История версий сохранена без удаления записей. Её перенос — отдельная работа.

Каждая запись имеет постоянный номер, код, тип Долг/Патч, части проекта,
дату создания и реализации либо прочерк при отсутствии доказательства даты.
Незавершённая работа остаётся долгом. Смена типа после завершения не меняет ID.

Есть совместные фильтры по типу, частям (AND), точному номеру, тексту и двум
диапазонам дат, сортировка и страницы. Фильтры сохраняются в ссылке, есть RU/EN.
Личные CRM-данные в справочник не входят. Код CRM и контейнер v1 не меняются;
ядро получает только общую версию и ссылку из Help.

Проверки модели и браузера покрывают совместные условия, границы дат, URL,
сброс, пагинацию, безопасный текст, недоступный storage и восемь viewport.
Это не закрывает остальные долги проекта и не заменяет их приёмку.

[Правила](work-directory.md), [фактический выпуск](release-v17.11.114-receipt.md).
Предыдущий v17.11.113 сохраняется как точка отката.

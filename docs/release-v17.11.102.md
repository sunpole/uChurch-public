# uChurch v17.11.102

## RU

После завершения работы прежнего серверного контура публичный вход и рабочие
контуры восстановлены на новом сервере и перенесены на домен `.pro`.

- `uchurch.pro` остаётся единственной индексируемой публичной страницей.
- `staging.uchurch.pro` остаётся синтетической Demo.
- `pilot.uchurch.pro` снова ведёт по шагам создания новой временной базы или
  открытия зашифрованной `.uchurchdb` с выбором оператора.

Работа Pilot проверена на синтетических данных. Базы церквей, пароли,
recovery-файлы и журналы не входят в публичный релиз.

## EN

After the previous server environment was retired, the public entry and
working environments were restored on a new server and moved to the `.pro`
domain.

- `uchurch.pro` remains the only indexable public page.
- `staging.uchurch.pro` remains a synthetic Demo.
- `pilot.uchurch.pro` again guides the owner through creating a temporary
  database or opening an encrypted `.uchurchdb` and choosing an operator.

Pilot behavior was checked using synthetic data. Church databases, passwords,
recovery files and logs are not part of this public release.

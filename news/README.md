# uChurch Public News

uChurch development notes for uNews are published from this folder. Every post
is written in Russian and contains only a verified public statement, its main
link and one tag set. uNews also adds the public showcase link when the main
link points elsewhere; do not duplicate it in the body. Existing uChurch posts
receive a showcase URL button without replacing their text or images.
Never add source code, CRM records, exports, credentials,
private paths, recovery data or personal church information.

Keep the tone of a public development channel, not a personal blog. Describe
product changes and verification limits without naming internal testers,
family members or participants in owner acceptance. Keep personal follow-up
in private task discussions. Correct existing posts in place, without duplicates.
